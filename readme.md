# Student Opinion Sentiment Analysis

## Overview
This project was developed for academic purposes to analyze student opinions and comments using Python. It processes text, identifies sentiment polarity, classifies comments, and presents results through frequency analysis and visualizations.

## Features
- **Text Cleaning:** Processes comments to prepare them for analysis.
- **Sentiment Analysis:** Identifies sentiment polarity and labels comments according to their sentiment.
- **Comment Classification:** Displays the distribution of sentiment categories.
- **Word Frequency Analysis:** Identifies the most frequent words in student comments.
- **Classification Evaluation:** Evaluates predictions against existing sentiment labels.
- **Data Visualization:** Generates graphs to present analysis results.
- **New Comment Analysis:** Allows users to enter a comment and analyze its sentiment.

## Technologies Used
- **Language:** Python
- **Libraries:** Pandas and the libraries required for text processing, evaluation, and visualization.
- **Concepts:** Natural Language Processing (NLP), Sentiment Analysis, Text Preprocessing, Data Analysis, and Data Visualization.

## Project Structure
- `main.py` — Main program and interactive menu.
- `datos.py` — Loads comments and sentiment labels.
- `limpieza.py` — Cleans and preprocesses text.
- `sentimientos.py` — Analyzes sentiment and processes new comments.
- `frecuencia.py` — Analyzes word frequency.
- `evaluacion.py` — Evaluates classification results.
- `graficas.py` — Generates data visualizations.

## Requirements
- Python 3.10 or later for the `match` statement.
- The Python libraries imported by the project modules.

## Installation and Execution
1. Clone or download this repository.
2. Install the required Python libraries.
3. Ensure the comment dataset is available in the expected location.
4. Run the main program:

```bash
python main.py
```
